# MAR DE GIRASSÓIS — Cena da Dança (Cena 11 / 11B / 12)

Projeto organizado para animação no **After Effects** (fluxo híbrido com Premiere).

## Como usar esta pasta
1. Leia o **`DECUPAGEM_MAPA.md`** — a cena inteira em tabela (tempo → ação → material).
2. Leia o **`GUIA_MONTAGEM.md`** — passo a passo no AE (setup, chroma key, linha
   de costura, efeito borracha).
3. Baixe os clipes do Google Drive e coloque em cada subpasta de
   `01_MATERIAIS/` — **cada pasta tem um `_LISTA.md`** dizendo exatamente quais
   arquivos vão nela, na ordem, com o link de cada um.

## Estrutura
```
00_PROJETO/          → arquivos .aep / .prproj
01_MATERIAIS/        → clipes-fonte, numerados NA ORDEM da cena
   01_[00.00-00.15]_COSMICOS
   02_[00.15-00.24]_FOGO
   03_[00.24-00.39]_TERRA
   04_[00.39-00.47]_AGUA
   05_[00.48-01.00]_AR
   06_[01.08-01.30]_FOGO_CHAO
   07_[01.30-01.49]_COSTURA_EFEITOS   (⚠️ linha de costura = criar no AE)
   08_[01.49-01.55]_LINHA_VERMELHA
   09_[01.55-02.28]_PINCELADAS_FINAL
02_COMPS_AE/         → pré-comps exportadas / trabalho do AE
03_AUDIO/            → música e referência da coreografia
04_EXPORTS/          → renders finais
```

> O vídeo é composto pelas próprias imagens das pastas (não há take base da
> dançarina). Sequência elemental: cósmico → fogo → terra → água → ar → pintura.
